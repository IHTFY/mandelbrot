# Agent instructions

Mandelbrot is a static browser game, live at https://mandelbrot.ihtfy.com.

Security stage: public

Polish: low: keep it working with no glaring bugs; fix only obvious or reported bugs, with no speed tuning or repeated checks.

Rules: the web games manager's `AGENTS.md` (repository `IHTFY/web-games`) applies here, including the ad rules. Work on a branch, open a pull request against `master`, and merge after checks pass; pushing `master` deploys the site.

Commits, pull requests, issues, and files here are public. Keep out secrets, personal details, local machine paths, and the names of the tools or models that wrote or reviewed the code.
